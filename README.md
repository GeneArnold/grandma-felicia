Pull the slot machine, win (or lose) your Christmas coins, and hit the bonuses: scratch-off tickets and a
visit from Santa. Every part of it plays with one tap.

No ads, no real money, no sign-up. Plain HTML and JavaScript on [Phaser 3](https://phaser.io), installable
on your phone's home screen.
